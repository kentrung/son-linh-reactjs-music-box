# Mini Music Box
- Thiết kế thanh phát nhạc thu nhỏ (mini player) gọn gàng ở góc màn hình, tối ưu không gian hiển thị.
- Hỗ trợ đầy đủ các tính năng cơ bản như Play/Pause, hiển thị ảnh bìa album (Artwork), tên bài hát và tên nghệ sĩ.
- Trải nghiệm điều khiển nhạc nhanh chóng, mượt mà trên nền tảng web.
